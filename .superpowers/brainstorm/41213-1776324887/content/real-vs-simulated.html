How do we handle honesty in the scan?

You said it: if they don't need us, we tell them. That changes everything.

A

Build the real backend first

Before we touch the Hero, we build a serverless function that calls Google Places API + PageSpeed API when they enter their URL. Real star rating. Real page speed. Real review count. Real competitor data. If their site is great, the report says so. No faking anything.

Takes longer. Pauses the rating loop. But the feature ships honest from day one.

B

Ship the UX now, wire real data later

Build the scan flow in the Hero now, but instead of showing fake scores, the scan captures their URL and tells them: "Your full report is being generated. Check your email within 24 hours." You manually run the real audit and send them personalized results. Phase 2 automates it.

Ships fast. Still honest. You do the real work behind the scenes until the API is built.

C

Skip the scan feature entirely for now

Keep the Hero as-is (GOLD). Focus on getting all 13 sections to GOLD first. Come back to the scanner as a separate project after the site ships. The site is already strong without it.

Fastest path to shipping. Scanner becomes its own project.
