Real Scanner: API Architecture

What we call, what it returns, what it costs, and how it flows.

Data Sources

Google PageSpeed Insights API Free / no key needed
  • Performance score (0-100, real Lighthouse audit)
  • First Contentful Paint (how fast something shows up)
  • Largest Contentful Paint (how fast the main content loads)
  • Mobile vs Desktop scores (separate audits)
  • SEO score (meta tags, headings, alt text, crawlability)
  • Accessibility score (contrast, labels, structure)
  • Best practices score (HTTPS, image formats, JS errors)
Google Places API $17 per 1,000 lookups
  • Star rating (actual Google rating, e.g. 3.2)
  • Total review count
  • Recent reviews with text (what customers actually said)
  • Business hours (are they accurate?)
  • Business category (plumber, HVAC, etc.)
  • Photos count
  • Competitor data (nearby businesses in same category with their ratings)
Direct Website Crawl (fetch + parse) Free / serverless function
  • SSL certificate (valid, expired, missing)
  • Title tag and meta description (present, length, quality)
  • H1 tag (present, relevant)
  • Mobile viewport meta (responsive or not)
  • Phone number visible (can customers find it?)
  • Click-to-call link (does the phone number work on mobile?)
  • Schema markup (does Google know what this business is?)
  • Contact form present

How It Flows (10-15 seconds total)

1

Visitor enters URL

Frontend sends their URL to a serverless function (Netlify Function or Cloudflare Worker)

instant
2

Serverless function fires 3 requests in parallel

PageSpeed API + Google Places search (find business by URL) + direct fetch of their homepage. All three run simultaneously.

3-8 seconds
3

Results stream back to frontend

As each API responds, results populate the terminal line by line. Website crawl results show first (fastest), then PageSpeed, then Places. Each line appears as it arrives.

results appear progressively
4

Report card generates from real data

Scores calculated from actual API responses. Grade assigned based on weighted formula. Revenue leak estimated using industry averages multiplied by their actual gaps.

instant (client-side math)
5

Lead captured + email queued

URL + email stored. Full detailed report generated and queued for email delivery (deeper analysis than what shows on screen).

background

The Honesty Engine

If their site scores 80+, we say: "Your website is in good shape. Here are a few areas that could still improve." We show them what's working (green bars) alongside what's not. No scare tactics.

If their reviews are strong (4.5+ stars, 50+ reviews), we say: "Your reputation is solid. Customers trust you." We highlight it as a strength.

If they genuinely don't need us, the report says so. And that honesty is the thing that makes them remember us when they DO need help, or when they refer a friend who does.

The revenue leak estimate only counts real gaps. If their site is fast, we don't add "slow website" to the leak. If they respond to reviews, we don't ding them for it. Real numbers only.
