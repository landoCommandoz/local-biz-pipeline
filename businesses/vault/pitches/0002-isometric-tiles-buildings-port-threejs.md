# Pitch 0002: Isometric Building Starter Kit

**Scout target:** isometric-tiles-buildings
**Pack size:** 132 PNG sprites, 1.6 MB
**License:** CC0

## Product angle

Pre-configured Three.js isometric city builder with 132 building sprites from Kenney's pack. Buildings include residential, commercial, and industrial tiles optimized for browser games. Package includes sprite loader, basic camera controls, and grid placement system.

Target is indie devs who want to prototype city builders or management games without setting up 3D pipelines. Saves 8-12 hours of boilerplate setup work.

## Price

$19

## Target audience

Indie web developers on Itch.io building browser-based simulation or strategy games.

## Projected sales in month 1

15-25 units ($285-475 revenue). Assumes similar performance to other Three.js starter packs on Itch. Isometric city builders are proven popular in game jams.

## Build effort

Medium effort, 12-16 hours. Three.js scene setup, sprite optimization for web, basic grid system, and documentation.

## Risks

- Three.js version compatibility issues as library updates frequently
- Kenney assets widely available free, value proposition must be in the setup work
- Limited appeal outside web game developers
