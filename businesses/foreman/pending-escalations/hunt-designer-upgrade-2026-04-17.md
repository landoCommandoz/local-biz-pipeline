## Context for Lando

The current `designer-claude-sonnet` hire is not bad at HTML, CSS, data wiring, or layout. It is bad at freehand character art. That is not a fixable prompt problem, it is a model-capability problem. A pure LLM drawing inline SVG tiny-human figures from scratch will keep coming back sloppy because each run reinvents the anatomy from text.

Three architectures ranked:

1. **Flux Schnell (generate) + Sonnet (compose).** Paid, under $1/month. Highest ceiling on character quality. Deterministic via fixed seeds. Solves sloppiness directly.
2. **Kenney CC0 (library) + Sonnet (compose).** Free. Highest floor on consistency. Blocky-isometric aesthetic, may or may not match the Stardew reference closely enough.
3. **Open Peeps (library) + Sonnet (compose).** Free. Hand-drawn line-work. Aesthetic is onboarding-SaaS, not rustic auto-yard. Flagged.

The designer hire does not get fired on this hunt. It stays as the HTML/CSS composer. What changes is where the character art comes from: no longer hand-drawn by Sonnet, now either generated by Flux or selected from Kenney.
